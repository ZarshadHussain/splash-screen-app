# [App Name]

An Android application built with Java in Android Studio that shows an animated
splash screen when the app launches, then opens the main screen.

## Features
- Splash screen with university logo, app name and tagline
- Fade and slide-in animations
- Loading bar that fills before the main screen opens
- Custom colors and theme for a clean look
- Main screen with a picture

## Tech Stack
- Language: Java
- IDE: Android Studio
- Min SDK: API 24 (Android 7.0)
- Layout: ConstraintLayout

## Project Structure
- `SplashActivity.java` - splash screen logic, animations and timer
- `MainActivity.java` - main screen shown after the splash
- `res/layout/activity_splash.xml` - splash screen design
- `res/layout/activity_main.xml` - main screen design
- `res/drawable/` - logo and loading bar drawables
- `res/values/colors.xml` - app color palette

## How to Run
1. Clone the repository.
2. Open the project in Android Studio.
3. Wait for the Gradle sync to finish.
4. Run the app on an emulator or a real device.
